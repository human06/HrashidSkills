# Ahold Delhaize ONE AI

Use this reference for `ah-one-ai`. The color roles come from the Corporate variant of the ONE AI styling kit.

| Corporate role | Source hex | Deck use |
|---|---|---|
| Salt | `#F9FAFB` | Light canvas and primary surface |
| Avocado | `#005555` | Light ink, logo and structural graphics |
| Mint | `#B2EEBB` | Secondary graphics and dark-mode logo |
| Apple | `#00C81E` | Primary action accent and pass graphics |
| Lime | `#C8F000` | Highlights |

Use light mode by default. The kit specifies light surfaces, so the dark appearance uses derived teal surfaces with lighter ink. Preserve the four graphic accent hexes in both appearances and use the `*-ink` tokens for text contrast. Reserve the destructive red and warning amber for status, with a visible label or symbol.

The public edition includes the Corporate palette and uses EuclidFlex when installed, with embedded Archivo as the fallback. Teams with authorized internal assets can register their local logo and font files in the [asset manifest](../assets/design-artifacts/manifest.json). Presenter names, affiliations and credits belong to the story.
